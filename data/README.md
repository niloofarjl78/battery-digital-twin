# Dataset

This project uses the NASA Battery Aging Dataset (B0005, B0006, B0007, and B0018).

The dataset contains charge, discharge, and impedance measurements collected during lithium-ion battery ageing experiments.

## Data source

NASA Ames Prognostics Data Repository:

https://www.nasa.gov/intelligent-systems-division/

The original MATLAB `.mat` files are not included in this repository. Users should obtain the dataset from its original or authorised distribution source and place the files in the `raw_data/` directory.

## Dataset files

- B0005.mat
- B0006.mat
- B0007.mat
- B0018.mat

See the notebooks for data extraction, preprocessing, feature engineering, and analysis.
