## Dataset Usage

Download the [NASA Battery Data Set](https://phm-datasets.s3.amazonaws.com/NASA/5.+Battery+Data+Set.zip) and extract the following MATLAB files:

- `B0005.mat`
- `B0006.mat`
- `B0007.mat`
- `B0018.mat`

When running Notebook 01 in Google Colab, upload these four files when prompted. The notebook processes the files and exports the combined dataset to Google Drive.

The original MATLAB files are not stored in this repository because of their size.
